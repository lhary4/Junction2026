# Fonts of the portal page

The Valio Aimo web shop uses "National 2 Compressed" (Klim Type Foundry) and "Matter" (Displaay). Both are commercial and we have no licence, so their files are **not** in this repo. `portal.css` names them first: on a machine where they are installed, the page uses them.

The files here are the closest open fonts, both under the SIL Open Font License 1.1 (free to use and to ship), downloaded from Fontsource on 14/11/2026:

| File | Font | Stands in for | Source |
|---|---|---|---|
| `sofia-sans-extra-condensed.woff2` | Sofia Sans Extra Condensed | National 2 Compressed (headlines, tags, buttons) | https://fontsource.org/fonts/sofia-sans-extra-condensed |
| `figtree.woff2` | Figtree | Matter (text) | https://fontsource.org/fonts/figtree |
